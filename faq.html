FAQ

Частые вопросы

Это бесплатно?

Да. Sunset Launcher распространяется под лицензией MIT, полный исходный код открыт на GitHub.

Нужна ли лицензия Minecraft?

Для входа через Microsoft нужна купленная копия игры. Также поддерживаются аккаунты Ely.by и офлайн-режим.

Windows пишет «Неизвестный издатель». Это безопасно?

Сборки пока не подписаны сертификатом Authenticode, поэтому SmartScreen предупреждает при первом запуске. Выберите «Подробнее» → «Выполнить в любом случае». Вы можете сверить контрольную сумму SHA-256 в GitHub Releases или собрать лаунчер из исходного кода.

Собирает ли лаунчер телеметрию?

Нет. Никакой аналитики и телеметрии нет. Токены хранятся локально в системном OS Keyring. Сетевые запросы отправляются только к Mojang, Modrinth, CurseForge, серверам метаданных загрузчиков, Adoptium, Microsoft / Ely.by и GitHub Releases.

Где хранятся файлы игры?

Linux: ~/.local/share/sunset-launcher. Windows: %LOCALAPPDATA%\sunset-launcher. macOS: ~/Library/Application Support/sunset-launcher. Внутри расположены профили, версии, библиотеки, ассеты и изолированные папки instances/<name>.

Доступны ли сборки для macOS и пакеты для Linux?

Да. На странице загрузки и в GitHub Releases публикуются сборки для Windows (установщик .exe и портативный .zip), Linux (.deb, .rpm и .AppImage для x64 и ARM64) и macOS (.dmg и .app.zip для Apple Silicon и Intel).

Как установить модпак?

Откройте вкладку Discover, выберите модпак из Modrinth или CurseForge и нажмите «Установить» — либо импортируйте локальный файл .mrpack. Лаунчер сам создаст изолированную сборку и скачает файлы.

Нужно ли устанавливать Java вручную?

Нет. Sunset находит установленные версии Java в системе и при необходимости скачивает подходящую среду Adoptium в свою директорию автоматически.

Игра вылетела. Где посмотреть причину?

Откройте вкладку Console, чтобы увидеть сводку сбоя и скопировать полный отчёт одной кнопкой. В большинстве случаев модпакам помогает увеличение лимита RAM или выбор пресета JVM в настройках сборки.

Как работают обновления?

Лаунчер проверяет GitHub Releases, сверяет контрольную сумму SHA-256 и предлагает установить обновление прямо из интерфейса.
