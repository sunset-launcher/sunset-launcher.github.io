FAQ

Частые вопросы

Это бесплатно?

Да. Sunset Launcher распространяется под лицензией MIT, исходный код открыт на GitHub.

Нужна ли лицензия Minecraft?

Для входа через Microsoft нужна купленная игра. Также поддерживаются аккаунты Ely.by и офлайн-режим.

Windows пишет «Неизвестный издатель». Это опасно?

Релизы пока не подписаны сертификатом, поэтому SmartScreen показывает предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае». Целостность можно проверить по файлу .sha256 или собрать лаунчер из исходников.

Собираете ли вы мои данные?

Нет. Никакой телеметрии и аналитики. Токены и аккаунты хранятся только локально. Сетевые запросы идут лишь к нужным сервисам: Mojang, Modrinth, загрузчики модов, Adoptium, Microsoft / Ely.by и GitHub для обновлений.

Где хранятся файлы игры?

Linux: ~/.local/share/sunset-launcher. Windows: %LOCALAPPDATA%\sunset-launcher. macOS: ~/Library/Application Support/sunset-launcher. Внутри — профили, аккаунты, версии, библиотеки, ассеты и изолированные папки сборок.

Есть ли версия для macOS и .deb пакет для Linux?

Да! На странице загрузки и в релизах sunset-launcher/sunset-launcher доступны .exe и .zip для Windows, .deb пакеты и бинарники для Linux (x64 и ARM64), а также .app и бинарники для macOS (Apple Silicon и Intel).

Как установить модпак?

Откройте вкладку Discover, найдите модпак на Modrinth и нажмите «Установить» — или импортируйте готовый .mrpack-файл. Лаунчер сам создаст сборку и скачает всё нужное.

Нужно ли ставить Java вручную?

Нет. Лаунчер находит установленную Java автоматически и может скачать подходящую версию Adoptium в свою папку.

Игра вылетает. Что делать?

Откройте вкладку Console — там будет баннер с крашем и кнопка копирования краш-репорта. Часто помогает увеличить RAM или выбрать пресет JVM в настройках сборки.

Как обновить лаунчер?

Sunset сам проверяет GitHub Releases и предложит установить новую версию прямо из интерфейса.
