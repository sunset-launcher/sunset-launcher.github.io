✨ Главное в v0.1.9 · CurseForge + нативные установщики

Поиск модов из CurseForge и пакеты для любой платформы

В разделе «Обзор» появилась полноценная поддержка каталога CurseForge наряду с Modrinth: поиск модов, ресурспаков, шейдеров и модпаков, фильтрация под версию и загрузчик инстанса, установка с зависимостями и отображение источника каждого файла.

Расширена доставка сборок под все популярные системы: добавлен полноценный мастер установки Windows (.exe на базе Inno Setup), Linux-пакеты .rpm и переносимые .AppImage (x64 и ARM64), а также образы диска macOS .dmg со значком приложения.

Выделенные серверы Minecraft и публичный туннель bore для «серых» IP

🌐 Главное нововведение · Dedicated Servers + bore

Свой сервер в пару кликов — даже за провайдерским NAT и серым IP

В лаунчере появилась полноценная вкладка управления выделенными (Dedicated) серверами. Создавайте и запускайте серверы на ядрах Vanilla, Paper, Purpur, Folia, Fabric, Quilt, Forge, NeoForge и Arclight с автоматическим подбором нужной версии Java, живой серверной консолью, редактированием server.properties и установкой модов или плагинов напрямую с Modrinth.

Чтобы друзья могли зайти к вам без Hamachi и Radmin VPN, добавлено два режима публикации порта: автопроброс через UPnP для «белых» IP и встроенное TCP-туннелирование через открытый клиент bore (bore.pub) специально для «серых» IP (CGNAT). Лаунчер автоматически скачивает bore, открывает порт в сеть и сразу показывает готовый публичный адрес для подключения.

  • Новое Менеджер выделенных серверов (Dedicated Servers): создание, настройка RAM/JVM, живой лог, отправка команд в stdin, плавная остановка и автоподбор Java 8/16/17/21.
  • Сеть Встроенный клиент bore (ekzhang/bore) для открытия сервера в интернет при «сером» IP (за NAT / CGNAT) через bore.pub, а также автопроброс портов по UPnP с автозакрытием при выключении сервера.
  • Новое Установка серверных модов и плагинов напрямую из Modrinth с учётом выбранного ядра (Paper, Purpur, Folia, Fabric, Forge, NeoForge, Arclight) и редактор основных параметров server.properties.
  • Защита Хранение токенов аккаунтов в системном хранилище ключей ОС (OS Keyring), атомарная запись JSON-конфигов с правами 0600, проверка SHA-256 при автообновлении и защита от уязвимостей Log4j.
  • Новое Поддержка классических версий Minecraft (установщики Forge ≤ 1.12.2, виртуальные ассеты версий до 1.7.3) и импорт модпаков из Prism Launcher и CurseForge.
  • Улучшено Пакетное обновление модов по хешам, управление датапаками миров, превью скриншотов, отмена активных загрузок, модульная архитектура UI и сборки для Linux ARM64 (.deb) и macOS.
  • Исправлено Ограничена длина пути Unix-сокета контроля единственного экземпляра лаунчера в пределах системного лимита sun_path.
