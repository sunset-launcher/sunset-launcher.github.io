CurseForge, инсталляторы для всех ОС, хуки запуска и адаптивный UI

Главное в v0.1.9 · CurseForge + установщики

Поиск модов из CurseForge и нативные пакеты для каждой платформы

В разделе «Обзор» появилась поддержка каталога CurseForge наряду с Modrinth: поиск модов, ресурспаков, шейдеров и модпаков, фильтрация под версию и загрузчик инстанса, установка с зависимостями и отображение источника каждого файла.

Сборки охватывают все настольные системы: мастер установки Windows (-setup.exe на базе Inno Setup), Linux-пакеты .rpm и переносимые .AppImage (x64 и ARM64), а также образы диска macOS .dmg.

  • Новое Установщики и новые форматы пакетов: мастер установки Windows (Inno Setup), пакеты .rpm и .AppImage для Linux (x64 и ARM64), а также .dmg и .icns-иконка для macOS.

Выделенные серверы Minecraft и публичный туннель bore для серых IP

Главное в v0.1.8 · Dedicated Servers + bore

Локальный сервер за провайдерским NAT без сторонних VPN

В лаунчере появилась вкладка управления выделенными серверами на ядрах Vanilla, Paper, Purpur, Folia, Fabric, Quilt, Forge, NeoForge и Arclight с автоматическим подбором Java, живой серверной консолью, редактированием server.properties и установкой плагинов и модов с Modrinth.

Для подключения друзей без Hamachi и Radmin VPN предусмотрены два режима публикации порта: автопроброс по UPnP для белых IP и TCP-туннелирование через bore (bore.pub) для частных адресов за CGNAT.

  • Новое Менеджер выделенных серверов (Dedicated Servers): создание, настройка RAM/JVM, живой лог, отправка команд в stdin, плавная остановка и автоподбор Java 8/16/17/21.
  • Сеть Встроенный клиент bore (ekzhang/bore) для открытия сервера в интернет при сером IP (за NAT / CGNAT) через bore.pub, а также автопроброс портов по UPnP с автозакрытием при выключении сервера.
  • Новое Установка серверных модов и плагинов напрямую из Modrinth с учётом выбранного ядра (Paper, Purpur, Folia, Fabric, Forge, NeoForge, Arclight) и редактор основных параметров server.properties.
  • Защита Хранение токенов аккаунтов в системном хранилище ключей ОС (OS Keyring), атомарная запись JSON-конфигов с правами 0600, проверка SHA-256 при автообновлении и защита от уязвимостей Log4j.
  • Новое Поддержка классических версий Minecraft (установщики Forge ≤ 1.12.2, виртуальные ассеты версий до 1.7.3) и импорт модпаков из Prism Launcher и CurseForge.
  • Улучшено Пакетное обновление модов по хешам, управление датапаками миров, превью скриншотов, отмена активных загрузок, модульная архитектура UI и сборки для Linux ARM64 (.deb) и macOS.
  • Исправлено Ограничена длина пути Unix-сокета контроля единственного экземпляра лаунчера в пределах системного лимита sun_path.
