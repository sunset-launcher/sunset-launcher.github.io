Установка

Как установить

  1. На Ubuntu / Debian / Mint установите .deb, на Fedora / RHEL / openSUSE — .rpm, либо используйте портативный AppImage или бинарник.
  2. Выберите нужный вариант установки в терминале:
Ubuntu / Debian — установка .deb пакета
$ sudo apt install ~/Downloads/sunset-launcher_0.1.9_amd64.deb
Fedora / RHEL / openSUSE — установка .rpm пакета
$ sudo dnf install ~/Downloads/sunset-launcher-0.1.9-1.x86_64.rpm
Любой дистрибутив — запуск AppImage
$ chmod +x ~/Downloads/sunset-launcher-0.1.9-x86_64.AppImage
$ ~/Downloads/sunset-launcher-0.1.9-x86_64.AppImage
Любой дистрибутив — запуск бинарника
$ chmod +x ~/Downloads/sunset-launcher-linux-x64
$ ~/Downloads/sunset-launcher-linux-x64
Проверка SHA-256 (по желанию)
$ sha256sum -c sunset-launcher-linux-x64.sha256

При установке .deb/.rpm или первом запуске бинарника лаунчер автоматически появится в меню приложений.

  1. Скачайте установщик sunset-launcher-windows-x64-setup.exe (либо автономный .exe / портативный .zip).
  2. Пройдите мастер установки (или просто запустите .exe — ярлык в меню «Пуск» создастся автоматически).
  3. Если появится SmartScreen: «Подробнее» → «Выполнить в любом случае».
PowerShell — проверка SHA-256
> Get-FileHash .\sunset-launcher-windows-x64-setup.exe -Algorithm SHA256
  1. Скачайте sunset-launcher-macos-arm64.dmg (Apple Silicon M1–M4) или sunset-launcher-macos-x64.dmg (Intel), либо .app.zip.
  2. Откройте .dmg (или распакуйте .app.zip) и перенесите Sunset Launcher.app в папку /Applications.
  3. Снимите карантин Gatekeeper перед первым запуском неподписанной сборки:
zsh / bash
$ xattr -cr "/Applications/Sunset Launcher.app"
$ open -a "Sunset Launcher"
Проверка SHA-256 (по желанию)
$ shasum -a 256 -c sunset-launcher-macos-arm64.dmg.sha256
  1. Установите Rust через rustup.
  2. Склонируйте репозиторий и соберите релиз:
bash
$ git clone https://github.com/sunset-launcher/sunset-launcher
$ cd sunset-launcher
$ cargo build --release
$ ./target/release/mc-launcher

Что нового

Sunset Launcher v0.1.9 — CurseForge, установщики ОС и хуки запуска

  • Поддержка каталога CurseForge наряду с Modrinth: поиск, фильтрация под версию/загрузчик и установка с зависимостями.
  • Новые форматы распространения: мастер установки Windows (.exe / Inno Setup), Linux .rpm и .AppImage (x64 / ARM64), а также macOS .dmg.
  • Хуки запуска (wrapper, pre-launch, post-exit), переменные окружения, просмотрщик логов инстанса и настраиваемый экспорт .mrpack.
  • Автономный режим Offline Mode, глобальные настройки инстансов по умолчанию и улучшенная адаптивность вкладок.
