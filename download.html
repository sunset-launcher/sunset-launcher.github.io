Установка

Установка из пакета или терминала

  1. Установите .deb на Ubuntu / Debian / Mint, .rpm на Fedora / RHEL / openSUSE, либо запустите портативный AppImage.
  2. Выполните команду для вашего дистрибутива:
Ubuntu / Debian — пакет .deb
$ sudo apt install ~/Downloads/sunset-launcher_0.2.0_amd64.deb
Fedora / RHEL / openSUSE — пакет .rpm
$ sudo dnf install ~/Downloads/sunset-launcher-0.2.0-1.x86_64.rpm
Любой дистрибутив — портативный AppImage
$ chmod +x ~/Downloads/sunset-launcher-0.2.0-x86_64.AppImage
$ ~/Downloads/sunset-launcher-0.2.0-x86_64.AppImage
Проверка контрольной суммы SHA-256
$ sha256sum ~/Downloads/sunset-launcher-0.2.0-x86_64.AppImage

При установке .deb или .rpm ярлык Sunset Launcher автоматически добавляется в меню приложений.

  1. Скачайте установщик sunset-launcher-windows-x64-setup.exe или портативный архив .zip.
  2. Запустите мастер установки или распакуйте .zip в любую папку.
  3. При появлении окна SmartScreen выберите «Подробнее» → «Выполнить в любом случае».
PowerShell — проверка SHA-256
> Get-FileHash .\sunset-launcher-windows-x64-setup.exe -Algorithm SHA256
  1. Скачайте sunset-launcher-macos-arm64.dmg (Apple Silicon) или sunset-launcher-macos-x64.dmg (Intel).
  2. Откройте .dmg и перенесите Sunset Launcher.app в папку /Applications.
  3. Снимите карантин Gatekeeper перед первым запуском неподписанной сборки:
zsh / bash
$ xattr -cr "/Applications/Sunset Launcher.app"
$ open -a "Sunset Launcher"
Проверка контрольной суммы SHA-256
$ shasum -a 256 ~/Downloads/sunset-launcher-macos-arm64.dmg
  1. Установите инструментарий Rust через rustup.
  2. Склонируйте репозиторий и соберите релизный бинарник:
bash
$ git clone https://github.com/sunset-launcher/sunset-launcher
$ cd sunset-launcher
$ cargo build --release
$ ./target/release/mc-launcher

Примечания к актуальному релизу

Sunset Launcher v0.2.0 — CurseForge, установщики ОС и встроенный туннель

  • Интеграция каталога CurseForge наряду с Modrinth: поиск, фильтрация по загрузчику и версии и установка зависимостей.
  • Нативные пакеты для ОС: мастер установки Windows (-setup.exe), Linux .rpm и .AppImage (x64 и ARM64) и образы macOS .dmg.
  • Хуки запуска (wrapper, pre-launch, post-exit), переменные окружения, просмотр логов сборки и настраиваемый экспорт .mrpack.
  • Автономный режим Offline Mode, глобальные настройки сборок по умолчанию и исправления вёрстки на узких окнах.
